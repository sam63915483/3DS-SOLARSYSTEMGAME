# SK-1 Clone 3DS Port Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Turn the browser mockup in `C:\3ds\mockup` into a native homebrew app (`sk1.3dsx`) that runs on a modded original 3DS from the Homebrew Launcher, with the same features: touch keyboard with zoom/scroll, mic sampling with trim and crossfaded loop, five synth presets, five effects with presets, D-pad menus, circle pad bend/filter, scope visualizer.

**Architecture:** All audio is rendered by our own software mixer in C (mono float, 32728 Hz, 512-sample blocks) and streamed to one NDSP channel as stereo PCM16, because the 3DS DSP cannot run effects or synths. Everything that is pure math (keyboard layout, trim, loop crossfade, effects, synths, menu navigation) lives in portable C files with **no 3DS headers** and is unit-tested on the PC with a host compiler; only `main.c`, `platform_*.c` and the drawing files touch libctru/citro2d. Screen layouts are copied 1:1 from the mockup because it already runs at native 3DS resolution.

**Tech Stack:** devkitPro (devkitARM, libctru, citro3d, citro2d) installed through MSYS2 pacman; MSYS2 UCRT64 gcc for host tests; Azahar emulator for PC testing; `3dslink` or FTP (ftpd) to push builds to the console.

**Source of truth for behaviour:** the mockup JS in `C:\3ds\mockup`. When in doubt, read the corresponding JS function; the C port must match it.

## File structure

```
C:\3ds\app\
  Makefile                  devkitPro 3DS application makefile (from the template)
  source\
    main.c                  init, main loop, ties platform + core together (3DS only)
    platform_audio.c/.h     NDSP streaming: allocates wave buffers, refills them from the mixer (3DS only)
    platform_mic.c/.h       mic ring buffer drain into a Recording (3DS only)
    draw.c/.h               citro2d helpers: rect, line, circle, text at native coords (3DS only)
    ui_bottom.c/.h          bottom screen drawing + touch handling (3DS only, thin)
    ui_top.c/.h             top screen: scope, recording, sample views, tab bar, panels (3DS only, thin)
    core\
      keyboard.c/.h         port of keyboard.js (pure)
      sample.c/.h           trim, loop crossfade, Recording -> Sample (pure)
      voice.c/.h            sample voice + synth voices with envelopes, pitch bend (pure)
      synth.c/.h            the five synth instruments (pure)
      fx.c/.h               distortion, chorus, flanger, delay, reverb + presets (pure)
      mixer.c/.h            renders one block: voice -> pad filters -> fx chain -> stereo (pure)
      fxui.c/.h             menu navigation state machine, port of fxui.js (pure)
      dsp_util.c/.h         one-pole/SVF filters, LFO, delay line, fast tanh (pure)
  tests\
    minitest.h              tiny assert harness
    test_keyboard.c
    test_sample.c
    test_fx.c
    test_fxui.c
    test_mixer.c
    run_tests.sh            builds and runs all tests with host gcc
```

Every `core\*.c` file compiles with `gcc -std=c99 -Wall -Wextra -Werror` on the PC. If a core file ever needs `<3ds.h>`, the design is wrong; move that piece to a `platform_*` file.

- [ ] **Step 6: Write keyboard.c (direct port of keyboard.js)**

```c
#include "keyboard.h"
#include <stdio.h>
static const int ZOOM[ZOOM_LEVELS] = {5, 7, 10, 14, 20, 28, 36};
static const char *NAMES[12] = {"C","C#","D","D#","E","F","F#","G","G#","A","A#","B"};
static int iround(double v) { return (int)(v < 0 ? v - 0.5 : v + 0.5); }

int rect_contains(Rect r, int px, int py) { return px >= r.x && px < r.x + r.w && py >= r.y && py < r.y + r.h; }

void kb_init(Keyboard *kb) {
    int white = 0;
    for (int m = LOW_MIDI; m <= HIGH_MIDI; m++) {
        int pc = m % 12, i = m - LOW_MIDI;
        int black = (pc == 1 || pc == 3 || pc == 6 || pc == 8 || pc == 10);
        kb->isBlack[i] = black;
        kb->whiteIndex[i] = black ? white - 1 : white;
        if (!black) white++;
    }
    kb->whiteCount = white; kb->zoomIndex = 3; kb->scroll = 7;
}
int kb_visible_white(const Keyboard *kb) { return ZOOM[kb->zoomIndex]; }
int kb_max_scroll(const Keyboard *kb) { return kb->whiteCount - kb_visible_white(kb); }
void kb_set_scroll(Keyboard *kb, int s) { int m = kb_max_scroll(kb); kb->scroll = s < 0 ? 0 : (s > m ? m : s); }
static void set_zoom(Keyboard *kb, int idx) {
    if (idx < 0) idx = 0; if (idx >= ZOOM_LEVELS) idx = ZOOM_LEVELS - 1;
    if (idx == kb->zoomIndex) return;
    double centre = kb->scroll + kb_visible_white(kb) / 2.0;
    kb->zoomIndex = idx;
    kb_set_scroll(kb, iround(centre - kb_visible_white(kb) / 2.0));
}
void kb_zoom_in(Keyboard *kb) { set_zoom(kb, kb->zoomIndex - 1); }
void kb_zoom_out(Keyboard *kb) { set_zoom(kb, kb->zoomIndex + 1); }
void kb_visible_range(const Keyboard *kb, int *lo, int *hi) {
    int first = kb->scroll, last = kb->scroll + kb_visible_white(kb) - 1;
    *lo = -1; *hi = -1;
    for (int i = 0; i < KEY_COUNT; i++) {
        if (kb->isBlack[i]) continue;
        if (kb->whiteIndex[i] == first) *lo = LOW_MIDI + i;
        if (kb->whiteIndex[i] == last) *hi = LOW_MIDI + i;
    }
}
int kb_layout(const Keyboard *kb, Rect area, KeyRect *out, int max) {
    int n = 0, vis = kb_visible_white(kb);
    double ww = (double)area.w / vis;
    for (int i = 0; i < KEY_COUNT && n < max; i++) {
        if (kb->isBlack[i]) continue;
        int col = kb->whiteIndex[i] - kb->scroll;
        if (col < 0 || col >= vis) continue;
        int x0 = iround(area.x + col * ww), x1 = iround(area.x + (col + 1) * ww);
        out[n].midi = LOW_MIDI + i; out[n].black = 0;
        out[n].r = (Rect){x0, area.y, x1 - x0, area.h}; n++;
    }
    int bw = iround(ww * 0.6); if (bw < 4) bw = 4;
    int bh = iround(area.h * 0.6);
    for (int i = 0; i < KEY_COUNT && n < max; i++) {
        if (!kb->isBlack[i]) continue;
        int boundary = kb->whiteIndex[i] + 1 - kb->scroll;
        if (boundary < 0 || boundary > vis) continue;
        double cx = area.x + boundary * ww;
        out[n].midi = LOW_MIDI + i; out[n].black = 1;
        out[n].r = (Rect){iround(cx - bw / 2.0), area.y, bw, bh}; n++;
    }
    return n;
}
int kb_hit(const Keyboard *kb, Rect area, int px, int py) {
    KeyRect rects[KEY_COUNT]; int n = kb_layout(kb, area, rects, KEY_COUNT);
    for (int i = n - 1; i >= 0; i--) if (rect_contains(rects[i].r, px, py)) return rects[i].midi;
    return -1;
}
void kb_note_name(int midi, char out[8]) { snprintf(out, 8, "%s%d", NAMES[midi % 12], midi / 12 - 1); }
```

## Phase 2: Portable audio core (host-tested)

- **Task 2.1 sample.c:** `trim_range()` (threshold 0.02, 5 ms pre-roll, 60 ms tail), `make_loopable()` (2 ms start fade, 50 ms equal-power crossfade of tail into head, returns loopStart). Test with the same sine seam check as `looptest.mjs`: seam jump < 3x the per-sample step.
- **Task 2.2 dsp_util.c:** one-pole low-pass, state-variable filter (lp/hp/bp), sine LFO, interpolated delay line, `fast_tanh`. Test: SVF at 1 kHz attenuates a 10 kHz sine by more than 20 dB.
- **Task 2.3 fx.c:** the five effects in mono float with the exact same parameter names, ranges and presets as `effects.js`; reverb is Freeverb-style (4 combs + 2 allpasses), REVERSE preset becomes GIANT. Delay outputs L/R; mixer runs stereo from the delay onward. Test: delay with 0 feedback outputs one echo at the set time; distortion with drive 0 is unity gain.
- **Task 2.4 synth.c + voice.c:** phase-accumulator oscillators, attack/release envelopes, the five instruments from `instruments.js`, sample voice with linear interpolation and loop points, `voice_bend()`. Test: sample voice at midi 72 reads twice as fast as midi 60; supersaw voice output is non-zero and below 1.0.
- **Task 2.5 mixer.c:** `mixer_render(float *L, float *R, int n)`: voice -> pad low/high SVF -> fx chain -> stereo; NaN guard resets fx state. Keeps the last block for the scope. Test: renders silence when no voice; non-finite state is cleared.
- **Task 2.6 fxui.c:** port of `fxui.js` navigation (tab bar, effect panel, preset button, preset page). Test: port of `fxtest.mjs` and `presettest.mjs`.

## Phase 3: 3DS platform layer

- **Task 3.1 platform_audio.c:** `ndspInit`, one channel, stereo PCM16 at 32728 Hz, 4 wave buffers of BLOCK frames in `linearAlloc`, `audio_pump()` called every frame refills any buffer whose status is `NDSP_WBUF_DONE` from `mixer_render`, `DSP_FlushDataCache` after each fill.
- **Task 3.2 platform_mic.c:** `micInit` with a 0x10000 ring buffer, `MICU_StartSampling(PCM16_SIGNED, 32730, 0, size-4, looping=true)`, `mic_pump()` each frame copies new samples (since last `micGetLastSampleOffset`, handling wrap) into the Recording until 10 s; stop -> `sample_from_recording()`. Speakers muted (mixer master gain 0, fx state cleared) while recording.
- **Task 3.3 draw.c + ui_bottom.c + ui_top.c:** citro2d ports of `screens.js` and `fxui.js` drawing, same coordinates. Text through one `C2D_TextBuf` cleared per frame. Scope: last mixer block as a 400-point polyline plus the radial shape; frequency bars from 16 Goertzel bins.
- **Task 3.4 main.c:** loop = `hidScanInput` -> touch/D-pad/circle to state -> `mic_pump` -> `audio_pump` -> draw both screens. Circle pad: `hidCircleRead`, dx/dy divided by 150 and clamped to -1..1.
- **Task 3.5:** build `sk1.3dsx`, run in Azahar, push to console with `3dslink`.
